Demo facilitator guide

The session

This is a made-up guide for the demo town library. It exists so that the page around it can be tested.

  • 1. Opening the library
  • 2. The reading room
  • 3. Closing time

1. Opening the library

The doors open at nine. The first visitor of the day is usually the lighthouse keeper, who returns the same atlas every week.

The front desk

A visitor who asks for a card gets one at the front desk. The desk also keeps the lost umbrellas.

The return box

Books that come back through the return box are checked in before noon.

2. The reading room

The reading room is quiet. A lighthouse model stands on the shelf by the window, and nobody knows who built it.

Seats and lamps

There are forty seats and thirty-eight lamps, which is a long story.

ShelfWhat it holds
NorthMaps and sea charts
SouthCookbooks

The quiet rule

Whispering is fine. The copier is not quiet, so it lives in the hallway.

3. Closing time

At six the lamps go off one by one. The sea charts go back to the north shelf.

The last round

Somebody walks the last round and checks the reading room for sleepers.

The guide ends here.
