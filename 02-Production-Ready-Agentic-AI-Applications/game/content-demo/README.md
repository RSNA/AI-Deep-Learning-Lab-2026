# Demo pack

A small content pack that lets anyone run the game from this repository. It follows the format
of section 5 of `docs/ENGINEERING_SPEC.md` and was written from scratch for the purpose. It is
set in two public library networks. The player is the digital services director of one branch.

The pack holds all three phases: the global files, Phase 1, the canvas of Phase 2 and the year of Phase 3.
Its calibration anchors are estimates marked provisional.
