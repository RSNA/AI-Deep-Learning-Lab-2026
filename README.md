# RSNA AI Deep Learning Lab 2026

Welcome to the Deep Learning Labs at the RSNA 2026 Annual Meeting (Radiological Society of North America) in Chicago!

The Deep Learning Labs are one-hour, hands-on classes where you work with AI tools directly, from building AI agents and prototyping applications to evaluating, fine-tuning, and preparing data for deep learning models. This repository holds the materials for every lab, including Google Colab notebooks, slides, and supplementary files. Each lab has its own numbered folder, in the order the labs are held.

## The Labs

1. **[A Low-Code Introduction to AI Agents in Radiology](./01-Low-Code-Introduction-to-AI-Agents/)**: What makes an AI agent different from a chatbot, and how to build your own agents with no-code and low-code (Pydantic AI) tools.
2. **[Building Production-Ready Agentic AI Applications](./02-Production-Ready-Agentic-AI-Applications/)**: Multi-agent AI frameworks and the practical know-how needed to deploy connected LLM agents in real-world scenarios.
3. **[An Introduction to Foundation Models in Medical Imaging](./03-Introduction-to-Foundation-Models/)**: What foundation models are, how they work, and how to load and apply one to defined tasks. No prior knowledge assumed.
4. **[How to Evaluate a Deep Learning Model for Deployment in Real Practice](./04-Evaluating-Deep-Learning-Models-for-Deployment/)**: Evaluating models beyond research metrics, covering data drift, calibration, uncertainty, and human-in-the-loop monitoring.
5. **[Vibe Coding 101](./05-Vibe-Coding-101/)**: Prompt engineering and "vibe coding" to prototype radiology applications without prior programming experience.
6. **[Leveraging Pretrained Embedding Models for Your Data and Use Cases](./06-Pretrained-Embedding-Models/)**: Adapting open-weight, radiology-specific pretrained models to your own use case, with attention to data curation, validation, and operating points.
7. **[How to Fine Tune a Large Language Model](./07-Fine-Tuning-Large-Language-Models/)**: An end-to-end walkthrough of fine-tuning a vision-language model on a radiology dataset, from data preparation to failure analysis.
8. **[Sourcing and Preprocessing Medical Imaging Data for Vision-Language Models](./08-Sourcing-and-Preprocessing-Data-for-VLMs/)**: Building image-report datasets from the ground up, covering cohort selection, DICOM retrieval with pynetdicom, de-identification, and quality control.

## How to Participate

All lessons are designed to run in [Google Colab](https://colab.research.google.com/), a free, web-based Jupyter notebook environment hosted by Google. To take part:

- **Bring a laptop.** We recommend a recent computer running the [Chrome browser](https://www.google.com/chrome/).
- **Have a Google account.** You need one (e.g., Gmail) to use Colab. If you don't have one, please [create an account](https://accounts.google.com/signup) before the meeting. You can [delete the account](https://support.google.com/accounts/answer/32046) afterward if you wish.
- **Check your lab's folder before the session.** Some labs may ask you to complete extra setup in advance, such as creating a free account or API key. Any such steps will be listed in the lab's README.

Notebooks will be linked from each lab's folder with an **Open in Colab** button once materials are posted.
