## Overview

This interactive workshop shows how to use general-purpose, open-weight, pretrained radiology-specific models to build a specific AI application, with an emphasis on how the approach generalizes to any use case. The session runs in a Colab notebook, and the application is built with public data.

Specific learning areas include how to call and adapt the pretrained model, the importance of training data curation, validation techniques, and operating point selection. This year's edition features updated models and data.

## Learning Objectives

By the end of this session, participants will be able to:

1. Demonstrate how to adapt and deploy open-weight, pretrained radiology-specific AI models using public datasets and Colab notebooks.
2. Evaluate the impact of training data curation, validation strategies, and operating point selection on model performance and generalizability across clinical use cases.
