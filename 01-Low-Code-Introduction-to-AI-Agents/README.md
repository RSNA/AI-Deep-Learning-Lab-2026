## Overview

In this hands-on workshop, we will introduce the foundational concepts behind AI agents and how they differ from traditional large language model (LLM) interactions. Attendees will learn what makes an agent an agent, including the ability to use tools, maintain context, and take autonomous actions, and why these capabilities matter for real-world AI workflows.

The workshop provides practical experience building agents through both no-code and low-code approaches, giving attendees the skills to create their own AI agents. This session serves as the foundation for [Lab 02: Building Production-Ready Agentic AI Applications](../02-Production-Ready-Agentic-AI-Applications/), held later the same day.

## Learning Objectives

By the end of this session, participants will be able to:

1. Define what AI agents are and distinguish them from standard large language models (LLMs).
2. Explain core agent concepts, including tool calling and context definition.
3. Build a functional AI agent using a no-code platform.
4. Build a functional AI agent using a low-code framework (Pydantic AI).
